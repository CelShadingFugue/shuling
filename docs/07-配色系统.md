# 07 · 配色系统（主题色 / 语义色 / 深色 / 打印）

> 配套：[06-交互设计](06-交互设计.md) 第 5 节（卡片色）、[05-系统设计](05-系统设计.md)（`color` 存在哪）。
>
> 配色不是"挑好看"，是四套东西叠在一张屏上：**品牌色**、**语义色**、**数据色**、**中性色**。
> 混着用，屏幕必糊；分开用，后面加主题、加深色模式、加打印，都是改一处。

---

## 1. 四类颜色，各管一段

| 类别 | 例子 | 用在哪 | 谁能改 |
|---|---|---|---|
| **主题色（品牌）** | 按钮、选中框、焦点环、链接 | 只出现在**可点的东西**上 | 全局设置，6 选 1 |
| **语义色** | 成功 / 警告 / 危险 / 信息 | 横幅、徽标、冲突提示 | 固定，不开放 |
| **数据色** | 主线色、卡片色 | 只出现在**不可点的色条/底色**上 | 数据自带 |
| **中性色** | 背景、卡片、文字、分割线 | 铺满 90% 的面积 | 主题 |

**最关键的一条规则：主题色只出现在"可点"的东西上，数据色只出现在"不可点"的东西上。**
空间上不重叠，就算同色相也不会误读——这样就不需要为了避让主线色去改主题色。

---

## 2. 三层 token，组件只碰最上面一层

```
L0 基础色（primitive）  --teal-600: #2E6F6A;  --gray-900: #23262B; …
        ↓
L1 语义 token           --bg, --surface, --text-1, --border, --primary-600 …
        ↓
L2 组件 token           --chip-bg, --chip-border, --rail-width, --grid-line …
```

规矩：

- 组件里 **只允许写 `var(--chip-bg)`**，不许出现 `#2E6F6A`，也不许直接写 `var(--teal-600)`。
- L2 只引用 L1，L1 只引用 L0。
- 换主题 = 换 L0/L1 的一组值；换组件外观 = 改 L2。两者互不牵连。

---

## 3. 主题色：6 选 1，不做取色器

理由三条，都和"团队用"有关：

1. **自由取色必然撞主线色。** A 琥珀、C 紫、D 蓝已经在用了，用户随手选个紫，界面立刻有两种紫代表不同意思。
2. **深色模式和打印没法做。** 取色器给的是 hex，你要为每个自定义色再推一套深色值——不可能。
3. **四个人四个主题，汇报材料对不上。** 截图拼在一起像四个产品。

### 预设

| 主题 | primary-600 | primary-50（选中底） | 适合 |
|---|---|---|---|
| **青（默认）** | `#2E6F6A` | `#EAF2F0` | 继承现有视觉，最稳 |
| 靛 | `#35508C` | `#E8ECF5` | 更"工具感" |
| 赭 | `#8F6428` | `#F6EEE1` | 偏人文、不刺眼 |
| 紫 | `#5F5088` | `#EEEBF5` | 慎用，与 C 线同色相 |
| 绿 | `#3F7D4E` | `#E9F2EA` | 与 E 线同色相，慎用 |
| 石墨 | `#4A4E55` | `#EDEEEF` | 最中性，色弱友好 |

每个主题只配三个值：`-50`（底）、`-600`（主）、`-700`（hover/pressed）。
不给 `-100 ~ -500`，因为用不到，给了就会有人乱用。

## 4. 中性色阶（暖灰 10 级）

背景是暖白（`#FBFAF7`），所以灰要偏暖，否则会显脏。

| token | 值 | 用途 |
|---|---|---|
| `--n0` | `#FFFFFF` | 卡片、浮层 |
| `--n1` | `#FBFAF7` | 页面底 |
| `--n2` | `#F5F3EE` | 次级底（左轨、表头） |
| `--n3` | `#EFEDE6` | hover 底、网格线 |
| `--n4` | `#E2DFD6` | 边框 |
| `--n5` | `#CFCBBF` | 强边框、禁用边 |
| `--n6` | `#A9A49A` | 三级文字、图标 |
| `--n7` | `#7C786E` | 二级文字 |
| `--n8` | `#55524B` | 正文 |
| `--n9` | `#23262B` | 标题、主文字 |

文字只用三档：`--text-1 = n9`、`--text-2 = n7`、`--text-3 = n6`。再多就会出现"这两个灰到底哪个重要"的争论。

## 5. 语义色

| 语义 | 值 | 用在哪 | 面积 |
|---|---|---|---|
| 成功 | `#2F7D50` | 已保存、同步完成 | 只出现在小圆点/文字 |
| 警告 | `#A8671A` | 冲突、待确认 | 只出现在横幅和小徽标 |
| 危险 | `#A93A3A` | 删除、校验失败 | 按钮描边或文字 |
| 信息 | `#3C6E9F` | 提示、说明 | 文字 |

**两条禁令**：语义色不做大面积底色（会和卡片色打架）；警告色刻意比 A 线的琥珀更深更脏（`#A8671A` vs `#B5762A`），避免在时间线上被误认成主线色。

---

## 6. 深色模式：不是反色

深色不是把白变黑，是**把"纸+墨"换成"夜+灯"**。

| token | 亮色 | 暗色 | 说明 |
|---|---|---|---|
| `--bg` | `#FBFAF7` | `#14161A` | 不用纯黑，纯黑会显得界面"浮" |
| `--surface` | `#FFFFFF` | `#1A1D23` | 卡片比底浅一档，形成层次 |
| `--surface-2` | `#F5F3EE` | `#21252C` | 左轨、表头 |
| `--border` | `#E2DFD6` | `#2C313A` | 暗色下边框比背景亮，不是暗 |
| `--text-1` | `#23262B` | `#E8E6E0` | 不用纯白，纯白刺眼 |
| `--text-2` | `#7C786E` | `#B8B6B0` | |
| `--text-3` | `#A9A49A` | `#8A8F98` | |
| `--grid` | `#EFEDE6` | `#24272E` | 网格要几乎看不见 |

两部分要单独处理：

- **主线色要提亮 10–15%**，否则在深底上发闷、发脏。
  A `#D08F3F` · B `#3E8A84` · C `#8676B5` · D `#4F82B5` · E `#7A9B62` · P `#A0998A`
- **卡片色要从"浅底"换成"深底 + 同色相"**，不能简单变暗，否则和深色卡片糊成一片。
  c1 `#2A2318` · c2 `#1B2724` · c3 `#241F2E` · c4 `#1C252E` · c5 `#222716` · c6 `#2C1E1E` · c7 `#26221A` · c8 `#24241F`

阴影在深色下几乎无效，改用**边框 + 顶部 1px 微光**（`inset 0 1px 0 rgba(255,255,255,.04)`）来表达层级。

## 7. 投影与打印

- **投影主题（答辩用）**：背景纯白、文字纯黑、阴影全去掉、主线色条加粗到 5px、网格加深一档。教室的投影仪会把所有浅灰吃掉，可以用一个按钮切过去。
- **打印**：强制浅色主题，去掉阴影和背景图，保留色条；灰度下列用"明度差 ≥ 15%"区分，不靠色相。

---

## 8. 对比度与无障碍

| 组合 | 最低要求 | 说明 |
|---|---|---|
| 正文 / 背景 | 7:1 | 时间线上的任务名 |
| 次要文字 / 背景 | 4.5:1 | 时间、交付物 |
| 卡片文字 / 卡片底色 | 4.5:1 | 8 个色板都已验证 |
| 边框、图标 / 背景 | 3:1 | 非文字元素 |

三条补充：

- 焦点环 = 2px 主题色 + 2px offset，**不用颜色深浅表示焦点**（深色模式下会消失）。
- 颜色永远不是唯一编码：卡片有 id、图钉、头像点、组色条，四重冗余。
- 提供"色弱友好"开关：带颜色的卡片右上角加一个小三角（形状冗余）。

---

## 9. 色彩预算：面积配比

一条能防止界面变花哨的硬指标：

| 类别 | 面积占比 |
|---|---|
| 中性色 | **≈ 90%** |
| 数据色（组色条 + 卡片底） | ≈ 8% |
| 主题色（按钮、选中、焦点） | **≤ 2%** |

主题色一旦超过 5%，界面就开始像"配色方案"，而不是"工作台"。
这条比任何色值都重要——**颜色要少，才显得准。**

## 10. 实现约定

```css
:root { --primary-600: #2E6F6A; --bg: #FBFAF7; ... }
:root[data-theme="dark"] { --primary-600: #3E8A84; --bg: #14161A; ... }
:root[data-theme="contrast"] { --bg: #FFFFFF; --text-1: #000000; --grid: #D8D5CC; }
```

- 主题存在**视图态**（localStorage），不同步——每个人用自己的。
- 切主题只换 CSS 变量，**不重算任何几何**，也不触发 React 重渲染。几何和颜色必须解耦。
- 主题值不写进模型文件，`tasks/A1.json` 里只有 `color: "c3"` 这种 token。

## 11. 待定

1. **主题色要不要允许每人不同？** 建议允许（视图态），但对外截图统一用默认青——不然汇报材料会花。
2. **卡片色板要不要随主题变？** 不要。卡片色是数据，主题变了数据不能变。
3. **要不要一个"暗色自动跟随系统"？** 建议要，成本很低（`prefers-color-scheme`），夜间写代码的人会感谢你。
