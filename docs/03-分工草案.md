# 03 分工草案（内部工作稿）

> **用法**：这份是给明晚讨论用的底稿，不是结论。会上以"本人认领"为准，认领完把第 5 节改成最终版，再把第 6 节的短版措辞填进申请表。

> **2026-11-10 改版**：第 2、4、5 节里"把事分给人"的部分作废——现在只定 12 月的提交物，其余留空，等人动过手再选。
> 仍然有效的是：第 3 节四条接口约定（开放参与之后它更重要了）、第 6 节申请表措辞（它写的是主线归属，不是任务归属）。

## 1. 先说清楚：分工分的是"交付物"，不是"模块"

一句"我负责硬件"，三个月后必然吵架。因为它没说：交给谁、什么时候交、什么算交完了。

所以每条线必须写成三句话：

> **我负责把 ______ 做出来，它长这样 ______，别人拿到能 ______。**

例：
- ❌ "我负责语音模块"
- ✅ "我负责语音链路：做到按住说话 3 秒内出文字、能中途打断，并出一张每一步耗时的表；别人拿到这张表能看出瓶颈在哪"

## 2. 五条线：详细定义

### A · 硬件与结构

| 项 | 内容 |
|---|---|
| 交付物 | ① BOM 表（含 2 个替代型号和价格）② 供电方案（Pi 一路 / 舵机一路 / 共地）③ 接线图 ④ 外壳 3D 文件（至少 2 版）⑤ 装好的整机 |
| 第一周产出 | 树莓派进盒子，屏幕/摄像头/麦克风/喇叭插上，通电开机，能出声 |
| 门槛 | 会看引脚图、会用万用表、会拧螺丝。不需要会画 PCB |
| 会学到 | 电源完整性、地线、去耦、结构公差、3D 打印、BOM 管理 |
| 主要坑 | 舵机共电源导致 Pi 重启；USB 麦克风底噪；外壳挡住摄像头视场；Pi 5 电源不够 |
| 上游/下游 | 给 B 提供音频设备，给 D 提供摄像头位置，给 E 提供装配步骤 |

### B · 语音链路

| 项 | 内容 |
|---|---|
| 交付物 | ① VAD（可以先按键代替）② 唤醒（第二阶段再做）③ 流式 ASR ④ TTS ⑤ 打断 ⑥ **延迟打点表** ⑦ 断网降级 |
| 第一周产出 | 在自己笔记本上：按住键说话 → 出文字 → 出回答 → 出声，并打印每段耗时 |
| 门槛 | 会装 Python 包、看得懂报错。**零基础可以，因为它全程在电脑上** |
| 会学到 | 音频流、采样率、WebSocket、异步、延迟预算、API 调用 |
| 主要坑 | 采样率不匹配；回声被自己识别；句尾判定太早/太晚；接口限流；TTS 首包慢 |
| 上游/下游 | 从 C 拿回答文本，向 E 提供 `/chat` 接口，用 A 的麦克风 |

### C · 大脑与知识库

| 项 | 内容 |
|---|---|
| 交付物 | ① 教材知识点结构（一章起步）② RAG 库（Dify / RAGFlow）③ prompt 与教学策略 ④ **20 条评测集** ⑤ badcase 记录 |
| 第一周产出 | 一章教材整理成 30 个问答对；用 20 个问题考现有模型，记录答错原因（没查到 / 查到了胡说 / 答非所问） |
| 门槛 | 不需要强编程，需要耐心、判断力、愿意读教材 |
| 会学到 | RAG、检索质量、prompt 工程、评测方法、怎么把"感觉不行"变成"指标不行" |
| 主要坑 | 把"模型胡说"误判成"检索不好"；没有评测集就没法迭代；知识库越堆越乱 |
| 上游/下游 | 吃 D 的 OCR 文本，向 B 提供回答文本 |

### D · 视觉与数据

| 项 | 内容 |
|---|---|
| 交付物 | ① 教材页数据集（≥200 张，含光照/角度变化）② 页面与区域检测 ③ OCR ④ 指读定位（手指或笔尖） |
| 第一周产出 | 手机拍 100 张课本页，跑一个现成 OCR，统计识别率，看看有多惨 |
| 门槛 | 会标注、会用 Colab 或本机 GPU。**没有显卡会很慢** |
| 会学到 | 数据集构建、YOLO、OCR、坐标变换、模型评估 |
| 主要坑 | **这是最难的一条**，光照一变就废；数据不够时怎么调都没用；不要在第一阶段碰 |
| 上游/下游 | 向 C 输出 `{page_id, bbox, text}` |

### E · 系统与交付

| 项 | 内容 |
|---|---|
| 交付物 | ① `install.sh` 一键安装 ② systemd 开机自启 ③ 日志与耗时看板 ④ 演示机镜像 ⑤ 仓库结构与 README ⑥ 演示视频 ⑦ 答辩材料 |
| 第一周产出 | 写一个 `install.sh`，让第二个人在一台干净系统上照它跑通 hello world |
| 门槛 | 会用 git、会写 shell。不难，但要细 |
| 会学到 | 部署、可复现、文档工程、CI 的基本想法 |
| 主要坑 | "这台能跑那台不能"；密钥写进仓库；演示机被改坏没有备份 |
| 上游/下游 | 和所有人对接；定义状态机与配置规范 |

## 3. 接口约定（比分工更重要）

分工分的是"谁交什么"，接口定的是"怎么接"。**这三条定下来，四个人可以并行一个月不互相阻塞；定不下来，第三个月全在等人。**

### 3.1 语音接口（B 对外，A 和 E 消费）

```
POST /chat
  请求: {"text": "……", "session_id": "……"}
  响应: {"text": "……", "audio": "/tmp/xxx.wav",
         "timings": {"asr": 0.42, "retrieval": 0.08, "llm": 1.21, "tts": 0.33},
         "ok": true}
```

规则：A 不用知道里面用了什么模型；B 不许改字段名不通知。

### 3.2 视觉接口（D 对外，C 消费）

```
POST /look
  响应: {"ok": true, "page_id": "math-g8-p72",
         "page_bbox": [x, y, w, h],
         "text": "……", "region_bbox": [x, y, w, h]}
  失败: {"ok": false, "reason": "no_page_found"}
```

规则：永远返回结构化的东西，不许返回一句话描述。C 只吃这个结构。

### 3.3 状态机（E 定义，A 消费）

```
IDLE → LISTEN → THINK → SPEAK → IDLE
                    ↘ ERROR → IDLE
```

规则：A 只按状态驱动灯和舵机，**不自己判断"它现在是不是在想"**。状态由 E 统一广播（WebSocket 或 MQTT 都行）。

### 3.4 配置

所有密钥、模型名、端口走 `.env`，`.env` 进 `.gitignore`，仓库里只放 `.env.example`。这条谁违反谁请客。

## 4. 三条土规矩（会上要念出来）

1. **一条线最多两个人。** 三个人做一件事，等于没人做。
2. **每人至少有一条能独立演示的路径。** 不被别人卡死，答辩也有话讲。
3. **没产出就在站会上说，别拖到期末。** 拖到期末的，最后都是别人替你补。

## 6. 写进申请表的措辞

### 短版（表格里，每格 25–35 字）

| 人 | 核心分工 |
|---|---|
| 李金峰 | 硬件与结构：选型采购、供电与接线、外壳与整机装配、稳定性验证 |
| 冯百懋 | 语音链路与系统交付：VAD/ASR/TTS 流式链路、端到端延迟优化、部署与文档 |
| 李美蓉 | 知识库与教学策略：教材知识整理、RAG 检索、问答评测集与 badcase 分析 |
| 张子涵 | 视觉与数据：教材图像采集标注、页面检测、OCR 与指读定位 |

### 长版（如果申请表有附页，或老师要细则）

每人格三句：负责什么 / 交付什么 / 和谁对接。

> **李金峰**：负责硬件选型、采购、供电方案与整机结构装配。交付 BOM 表、接线图、3D 外壳文件与可连续运行 2 小时的整机。与语音线对接音频设备，与系统线对接装配与开机自启。
>
> **冯百懋**：负责端侧语音链路（VAD、ASR、TTS、打断、流式响应）与系统集成交付。交付延迟分解报告、`/chat` 服务接口、一键部署脚本与项目仓库文档。与知识库线对接回答生成，与硬件线对接麦克风与扬声器。
>
> **李美蓉**：负责教材知识库构建、RAG 检索与教学策略设计。交付知识点结构、检索库、20 条评测集与试用期 badcase 分析报告。与视觉线对接 OCR 文本，与语音线对接回答文本。
>
> **张子涵**：负责教材图像数据集建设、页面检测与 OCR、指读区域定位。交付数据集、检测/识别模型与结构化视觉接口。与知识库线对接页面文本与区域坐标。

**写这两版的原因**：短版给评审看，长版给老师和未来的自己看。评审只看"四个人都有活、活不重叠"；老师会问"具体做什么"，那时候翻长版。

## 7. 反模式（贴在墙上）

| 反模式 | 后果 | 改法 |
|---|---|---|
| "我负责硬件" | 没交付物，无法验收 | 改成三句话模板（第 1 节） |
| 一个人接三条线 | 其他人变观众，项目变成个人项目 | 每人一条主线，最多兼一条 |
| 按难易分人 | 弱的人永远做文档，越来越边缘 | 按"兴趣 + 能独立交付"分，难度用时间摊 |
| 分工写死一年 | 三个月后没人认 | 每阶段末重认一次，换线要说一声 |
| 只分模块不定接口 | 联调时互相甩锅 | 第 3 节的四条约定 |
| 分工只写进申请表 | 交完就忘了 | 群里置顶 + 站会每周对一遍 |
